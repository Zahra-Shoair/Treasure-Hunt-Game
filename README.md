# Treasure-Hunt-Game
A simple console-based game built using Python. I created it for a one-week ITI course as my graduation project. It was my very first programming project, and I am proud to say it won me 2nd place.

# About
Navigate through a 9x9 grid to collect treasure symbols and earn points.

Buy various themes from the in-game store with your points.

# Features 
- Move your avatar by simply typing "left", "right", "up", or "down" into the console.
- Collect different prize symbols, each having different point values.
- Manage and change your treasure themes.
- Buy new themes from the store using the points earned.
- Exit the game anytime by typing "exit".
